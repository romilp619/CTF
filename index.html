CTF write-ups

Intigriti's monthly challenge, worked through end to end. How the bug was found, what got ruled out on the way, and how it should have been written.

  • Challenge 1126November 2026Signature bypass · RCE

    The signature that covered the wrong bytes

    A server that only runs RSA-2048 signed code, and publishes a working signed example in its own help text. The signature verifies. It just does not cover the bytes that run.

  • Challenge 1026October 2026Business logic

    The coupon that never runs out

    A €666 box, €66 of credit, and a duplicate check that only ever looks at the last promotion applied. Alternate two codes and the discount never stops.

  • Challenge 0926September 2026SQL injection

    Critter Gallery

    A base64-wrapped parameter that turns out to be an encoding rather than a filter, a case-sensitivity differential, and a database table the app never references.

  • Challenge 0826August 2026Stored XSS

    Bad Reception

    Prefix-only validation, stored HTML injection into an admin bot, and a JSONP gadget already sitting on the origin.

  • Challenge 0726July 2026Parser differential

    Canonically Yours

    Duplicate JSON keys parsed two different ways, so authorization validates one package while the report renderer uses another. The same check-one-thing, use-another shape as 1126.
